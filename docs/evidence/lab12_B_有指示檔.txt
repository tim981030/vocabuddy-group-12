## 計畫：新增純函式 `countDue`

### 為什麼要做
`index.html:113` 用 `WORDS.filter(w => stateOf(w).due <= today())` 算出今天要複習的單字。這段寫在碰 DOM 和 localStorage 的程式碼裡，沒辦法單獨測試。改成 `srs.js` 裡的純函式之後，就能用 Node 測試，以後 UI 要顯示「今日待複習 N 張」也可以直接呼叫。

### 已經讀過的檔案
- `app/srs.js`：現有的 `schedule`、`INTERVALS`，還有檔尾匯出的寫法
- `app/test_srs.js`、`app/test_csv.js`：測試的寫法（`assert.deepStrictEqual`，最後 `console.log`）
- `app/index.html:86-113`：`vb-log` 的結構是 `{ [en]: { seen, wrong, box, due } }`。`stateOf` 碰到沒有紀錄、或是缺 `box` 的舊紀錄時，會把它當成今天到期
- `app/sw.js`：`CACHE = "ytp-vocabuddy-v2"`，`SHELL` 已經包含 `srs.js`

### 設計
- 寫法是 `countDue(words, log, today)`，回傳一個整數
- 判斷規則跟 `stateOf` 一樣：沒有紀錄、或缺 `due` 的單字算到期，其他的看 `due <= today`
- 不會修改傳進來的 `log`（`stateOf` 會寫回 `log`，這個函式不會）
- `today` 由呼叫端傳進來，不在函式裡讀時鐘

函式上方的註解和程式碼：
```js
// 用途：計算今天（today）已到期、該複習的單字數；沒有紀錄的新字也算到期
function countDue(words, log, today){
  return words.filter(w => {
    const s = log[w.en];
    return !s || s.due === undefined || s.due <= today;
  }).length;
}
```
匯出改成 `module.exports = { schedule, INTERVALS, countDue };`，只多加一項，原本的都不刪。
