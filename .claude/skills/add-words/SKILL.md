# 新增單字流程

1. 先讀 `app/words.js` 確認現有格式：每筆是 `{en:"…", zh:"…"}` 兩個欄位，不要自創欄位。
2. 新單字加在陣列最後；若是一個新主題，先加一行註解 `// ○○主題單字`。不要重排既有順序。
3. 加之前先檢查 `en` 是否已存在（不分大小寫）；已存在就跳過，並在回報裡說明跳過了哪些。
4. 在 `app/` 執行 `node check_words.js`，必須看到「words.js 檢查通過，共 N 字 ✓」才算完成，並回報實際的 N。
5. 若報「重複單字」，把重複的那筆移除，重跑第 4 步。
6. 再跑 `node e2_contract.js`，確認沒有把 loop、variable、debug 弄壞。
7. 改了 `words.js` 就把 `app/sw.js` 的 `CACHE` 版本號加一，讓瀏覽器換新快取。
8. 通過後才 commit，訊息格式：`feat: 新增 N 個「主題」單字`。
9. 不要自動推遠端，push 由組員自己執行。
